# AI 상담 채팅 ↔ 오디오 통합 + 정서 분석 스트립 — 설계

## 배경

`/student/chat`의 채팅 시나리오(학교폭력/우울감/진로)는 현재 대본을 자동 재생하는
애니메이션이다. 여기에 **오디오(음성) 입력**을 더하고, **카메라 기반 얼굴 분석
(MediaPipe FaceMesh/FaceLandmarker) + 음성 특징**을 텍스트 위험도에 결합하는
멀티모달 정서 분석을 얹는다. STT/TTS/위험도 스코어링은 시뮬레이션이고,
카메라 영상 수신과 얼굴 랜드마크 검출·시각화는 실제 구현이다.

## 핵심 결정

### 1. 대화 진행 방식: 자동 재생 → 사용자 주도 턴 진행

시뮬레이션이지만 "상담자가 텍스트로 말하거나 오디오로 말하는" 흐름을 보여줘야
하므로, 채팅형 시나리오는 **상담자(`me`) 턴마다 재생을 멈추고 하단 입력바에서
사용자가 직접 보내는** 방식으로 바꾼다.

- `me` 텍스트 턴: 입력창에 대본 문장을 **미리 채워두고**(수정 가능) 전송 버튼 또는
  Enter로 보낸다. 보낸 내용이 말풍선에 기록된다(`via: 'text'`).
- `me` 텍스트 턴을 **🎤 녹음**으로 보내는 경우: 녹음 UI → 정지 → "음성을 텍스트로
  변환하는 중…" 1.2초 → 대본 문장이 말풍선으로 기록된다(`via: 'voice'`, 말풍선
  아래 "🎤 음성으로 말함" 메타 표시).
- `me` 사진 턴: 입력바가 "🖼️ 사진 첨부해서 보내기" 버튼으로 바뀐다.
- `bot` 턴: 타이핑 인디케이터 0.8초 → 말풍선. 연속된 bot 턴은 자동으로 이어진다.
  각 bot 말풍선에는 🔊 듣기 버튼이 있고, 상단 "자동 읽기" 토글이 켜져 있으면
  새 bot 말풍선이 나올 때 자동으로 읽는다(TTS).
- 재생 컨트롤: 기존 ⏸/▶ 일시정지는 사용자 주도 진행에서 의미가 없어 제거.
  헤더에 🔊/🔇(자동 읽기), ↺(처음부터), ✕(나가기)만 둔다.
- 설문형 시나리오(`survey`)는 상담이 아닌 문항 응답 데모이므로 **변경하지 않는다**
  (카메라 스트립도 붙이지 않음).

### 2. 렌더링 방식: 전체 재렌더 → 프레임 1회 렌더 + 영역 패치

카메라 `<video>`/`<canvas>`와 녹음 파형 캔버스는 `innerHTML` 전체 재렌더에서
살아남지 못한다. 채팅형 시나리오 플레이어를 `js/screens/chat-session.js`로
분리하고, 진입 시 프레임(스트립·배너·메시지 영역·입력바 컨테이너)을 한 번 렌더한
뒤 이후에는 다음 세 영역만 갱신한다.

- `#chatLog`: 말풍선 append / 타이핑 인디케이터 토글
- `#chatInput`: 입력바 상태별 innerHTML 교체
- 스트립/배너: 텍스트·클래스만 갱신 (video/canvas 노드는 유지)

### 3. 얼굴 분석: MediaPipe Tasks Vision `FaceLandmarker` (실제 동작)

- CDN(`cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.14`)에서 `import()`로
  동적 로드. wasm은 같은 CDN, 모델(`face_landmarker.task`, 3.7MB)은
  `storage.googleapis.com`. 빌드 단계 없음.
- FaceMesh 478 랜드마크 + 52개 blendshape 출력. 카메라 썸네일(가로 96px) 위에
  테셀레이션 랜드마크를 실시간으로 그린다(좌우 반전).
- 처리 루프는 `requestAnimationFrame` + 약 15fps 스로틀. 결과는 EMA로 평활.
- 오프라인/CDN 실패 시 카메라 영상은 유지하고 "얼굴 분석 모듈을 불러오지
  못했어요" 상태만 표시한다.

### 4. 오디오 녹음: 실제 마이크 파형, STT는 시뮬레이션

- 🎤 탭 → `getUserMedia({audio})` → `AnalyserNode`로 프레임별 RMS를 뽑아
  Gemini 스타일 스크롤 막대 파형을 그린다. 정지 버튼으로만 종료.
- 정지 시 트랙을 모두 멈추고(저장·전송 없음) RMS 시계열만 `affect.js`에 넘겨
  "목소리 떨림" 지표를 계산한다.
- 마이크 권한 거부/없음 → 🎤 버튼 비활성 + 툴팁("마이크 권한이 없어 텍스트로만
  가능해요"). `navigator.permissions.query({name:'microphone'})`가 `denied`를
  주면 세션 시작 시부터 비활성.

### 5. TTS: 브라우저 `speechSynthesis`가 있으면 사용, 없으면 시뮬레이션

- `ko-*` 음성이 있으면 실제로 읽는다. 없으면 텍스트 길이 비례(글자당 90ms + 400ms)
  타이머로 "읽는 중" 상태만 보여준다. 어느 쪽이든 말풍선에 재생 애니메이션(막대
  3개)과 🔊 → ⏹ 토글을 표시한다. 한 번에 하나만 재생(새로 누르면 이전 취소).

### 6. 멀티모달 위험도 (시뮬레이션, `js/affect.js` 순수 함수)

| 신호 | 입력 | 계산 |
|---|---|---|
| 텍스트 | 지금까지 기록된 `me` 발화 | 위험 키워드 가중치 noisy-OR: `1 - Π(1 - w)` |
| 표정 | blendshape 점수 | 우울 = mouthFrown·browInnerUp, 불안 = browDown·eyeWide·mouthPress, 긍정 = mouthSmile·cheekSquint → `clamp(0.6·우울 + 0.5·불안 − 0.4·긍정)` |
| 음성 | 녹음 RMS 시계열 | 인접 RMS 차이의 표준편차 / 평균 RMS(변동계수)를 0~1로 압축 |
| 종합 | 위 셋 | `0.6·텍스트 + 0.25·표정 + 0.15·음성`, `THRESHOLDS`(0.35/0.65)로 L1/L2/L3 |

표정 라벨은 우울/불안/긍정 중 최대값이 0.25 미만이면 "중립". 음성 신호는
녹음이 한 번도 없으면 0. 표정 신호는 얼굴 미검출이면 마지막 값 유지가 아니라 0으로
감쇠한다.

### 7. 권한·검출 상태 UI

| 상태 | 표시 |
|---|---|
| 카메라 권한 없음/거부 | 스트립 썸네일에 📷🚫, 채팅 상단 고정 배너 "더 정확한 상담을 위해 카메라 권한을 허용해주세요" + [허용하기] 버튼(재요청) |
| 권한 있음, 얼굴 미검출 (1초 이상) | 배너 "카메라에 얼굴을 비춰주세요" (검출되면 즉시 사라짐) |
| 권한 있음, 검출 중 | 랜드마크 오버레이 + 표정 라벨 |
| 모델 로딩 중 | 썸네일 위 "분석 준비 중…" |
| 마이크 권한 없음 | 🎤 비활성 |

개인정보 고지: 세션 첫 메시지로 시스템 안내 말풍선("더 정확한 도움을 위해 표정과
목소리를 함께 살펴요. 카메라·오디오는 녹화·저장되지 않아요.")을 넣고, 스트립 아래에
"🔒 녹화·저장되지 않음" 캡션을 상시 표시한다.

### 8. 미디어 생명주기

- 시나리오 진입(`mount`) 시 카메라 시작. `hashchange`로 `/student/chat`을 벗어나거나
  ✕/처음부터/다른 시나리오 보기 시 `stop()`으로 모든 트랙·루프·TTS를 정리한다.
- 다른 탭에 갔다가 돌아오면 대화 기록·진행 상태는 모듈 상태에 남아 있으므로
  프레임을 다시 그리고 카메라를 재시작한다. 녹음 중이었다면 입력 대기 상태로 되돌린다.

## 파일 구조

```
js/affect.js                 신규 — 정서/위험도 순수 계산 함수
js/affect.test.js            신규 — node:assert 테스트
js/media/camera.js           신규 — CameraSession: getUserMedia + FaceLandmarker 루프 + 오버레이
js/media/recorder.js         신규 — MicRecorder: getUserMedia(audio) + Analyser 파형/RMS
js/media/tts.js              신규 — speak/cancel (speechSynthesis 또는 타이머 시뮬레이션)
js/screens/chat-session.js   신규 — 채팅형 시나리오 플레이어(상태머신 + 영역 패치 렌더)
js/screens/student.js        수정 — 채팅형 시나리오를 chat-session에 위임, 설문/피커 유지
css/styles.css               수정 — 스트립, 배너, 입력바, 파형, 말풍선 메타, 시스템 안내
```

## 제외 범위

- 실제 STT/TTS 엔진, 실제 위험도 모델 연동 없음. 음성/영상은 저장·전송하지 않음.
- 설문형 시나리오는 그대로(카메라 없음).
- 교사 화면과의 위험도 연동 없음.
- 녹음 재생(들어보기), 녹음 취소 후 재녹음 UI 없음 — 정지하면 곧바로 변환.
