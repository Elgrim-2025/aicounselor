# 학생 채팅 화면 — 시나리오 기반 고정 대화 애니메이션으로 전환

## 배경

기존 `js/screens/student.js`의 채팅 화면(`/student/chat`)은 자유 텍스트를 입력하면
키워드 매칭으로 의도를 분류해 템플릿 응답을 돌려주는 방식이었다(`classifyIntent`,
`CHAT_TEMPLATES`, `isCrisisText`). 데모 목적상 대화 내용이 매번 달라지고 스토리가
불명확하다는 문제가 있어, 미리 정해진 각본(시나리오)을 챗봇 UI 위에서 애니메이션으로
재생하는 방식으로 완전히 대체한다.

4개 시나리오를 제공한다: 🚨 학교폭력 피해, 💧 우울감·무기력, 🧭 진로 고민,
📋 마음 설문조사(학기초 정서·행동 설문의 디지털화 데모). 학교폭력 시나리오에는
"사진을 남겨두라"는 봇의 요청과, 학생이 사진을 보내는 대화 턴이 포함된다.

## 제거 범위

- `js/screens/student.js`: 자유 입력 채팅 렌더링(`renderChat`의 입력창/전송 로직),
  `SEED_CHAT`, `chatHistory()` 제거.
- `js/data.js`: `classifyIntent`, `CHAT_TEMPLATES`, `isCrisisText`, `appendChat` 및
  관련 `INTENT_KEYWORDS`/`CRISIS_WORDS` 상수 제거. `state.chat` 필드도 더 이상
  사용하지 않으므로 `loadState()` 기본값에서 제거.
- `js/data.test.js`: `classifyIntent` 관련 테스트 케이스 제거.

## 파일 구조 변경

```
js/scenarios.js          신규 — 4개 시나리오의 고정 대본 데이터 + 설문 문항/채점 로직
js/screens/student.js    수정 — renderChat을 "시나리오 선택 화면" + "재생 화면"으로 재작성
css/styles.css           수정 — 시나리오 카드, 타이핑 인디케이터, 사진 말풍선,
                          설문 문항 카드(PHQ-9 스타일 재사용), 요약 카드 스타일 추가
```

## 화면 흐름 (`/student/chat`)

라우트는 그대로 `/student/chat` 하나를 쓰고, 모듈 내부의 휘발성 상태(새로고침 시
초기화)로 두 화면을 전환한다.

1. **선택 화면 (기본 진입)**: 4개 시나리오 카드(🚨/💧/🧭/📋)를 세로로 나열. 카드
   탭 시 재생 화면으로 이동.
2. **재생 화면**:
   - `type: 'chat'` 시나리오(학교폭력/우울감/진로): 기존 `.chat-scroll` 말풍선
     레이아웃을 그대로 쓰되, 자유 입력창 대신 상단에 일시정지/재생 토글 + "처음부터
     다시" 아이콘만 배치. 턴을 순서대로 자동 재생.
     - 봇 턴: "●●●" 타이핑 인디케이터를 0.6~1초 보여준 뒤 말풍선으로 교체.
     - `photo` 턴: 회색 배경 + 🖼️ 아이콘의 중립 썸네일 말풍선(실제 이미지 없음).
     - 말풍선 등장마다 `.chat-scroll`을 하단으로 자동 스크롤.
     - 턴 사이 간격 약 0.8~1.2초(텍스트 길이에 비례, 상한 有).
   - `type: 'survey'` 시나리오(마음 설문조사): 3단계 하위 화면 전환.
     1. 도입 2턴은 위와 동일한 채팅 말풍선 애니메이션.
     2. 설문 응시: 기존 PHQ-9 응시 화면(`.progress-track`, 문항 카드, `.likert-row`)
        스타일을 재사용. 자동재생이 문항마다 `answerIndex`에 해당하는 버튼에
        `.picked`(선택됨) 스타일을 입히며 약 1.2~1.5초 간격으로 다음 문항으로 진행.
     3. 결과 요약 카드: 카테고리별(정서/관계/스트레스) 평균 점수 박스 + 안내 문구
        + `outro` 텍스트.
   - 재생 종료(모든 시나리오 공통): 마지막 안내 말풍선/요약 카드 아래 "다른 시나리오
     보기" 버튼 → 선택 화면으로 복귀.
   - 하단 "상담 요청하기" / "컨텐츠를 추천해요" 칩은 그대로 두되 비활성(`disabled`)
     스타일로 표시(클릭 무반응).

### 🚨 학교폭력 피해
1. 봇: 다솜아, 요즘 표정이 안 좋아 보여서 걱정했어. 무슨 일 있었어?
2. 나: 어제 학교에서... 애들 몇 명이 나를 때렸어.
3. 봇: 많이 놀라고 아팠겠다. 지금 몸은 괜찮아? 어디 다친 데는 없어?
4. 나: 팔이랑 등에 멍이 좀 들었어.
5. 봇: 그랬구나. 혹시 다친 부분이나 그때 상황을 사진으로 남겨둘 수 있을까? 나중에 도움이 많이 될 거야.
6. 나: (사진 전송 — 중립 썸네일 말풍선)
7. 봇: 잘 받았어. 이 사진은 상담선생님께 안전하게, 너의 동의 하에만 전달돼. [기록됨]
8. 봇: 언제, 어디서, 누가 그랬는지도 기억나는 만큼 말해줄 수 있어?
9. 나: 어제 방과 후에 체육관 뒤에서, 같은 반 애들 세 명이었어.
10. 봇: 말해줘서 정말 고마워. 너는 잘못한 게 하나도 없어. 이 내용은 담당 상담선생님께 바로 전달할게. 선생님이 곧 너에게 연락드릴 거야.

## 재생 애니메이션 디테일

- 봇 메시지 전 "●●●" 타이핑 인디케이터 0.6~1초 → 말풍선 교체.
- 말풍선 간 간격 0.8~1.2초(텍스트 길이 비례, 상한 有).
- 새 말풍선 등장마다 `.chat-scroll` 하단 자동 스크롤.
- 상단 컨트롤: 일시정지/재생 토글, 처음부터 다시보기. 재생 중 언제든 노출되며,
  일시정지 후 재생을 누르면 멈춘 턴부터 이어서 재생(처음부터 다시 시작하지 않음).
  "처음부터 다시보기"만 인덱스를 0으로 되돌린다.
- 설문 문항 자동 선택도 문항당 약 1.2~1.5초 간격으로 동일한 리듬 유지.
- 재생 중에는 자유 입력이 없으므로 `chat-inputbar`(입력창) 자체를 렌더링하지 않는다.
- 재생이 끝나 종료 상태가 되면 일시정지/재생 컨트롤은 숨기고 "다른 시나리오 보기"
  버튼만 노출한다.

## 디자인 시스템 추가 요소

- 시나리오 선택 카드: 기존 `.select-card`와 유사한 톤이나 리스트형 카드(아이콘 +
  제목 + 부제 + 우측 화살표)로 별도 클래스 추가.
- 타이핑 인디케이터: `.bubble.bot`과 동일한 톤의 로딩 점 3개.
- 사진 말풍선: 회색(`--line-soft`) 배경 + 🖼️ 아이콘, 하단에 파일명 바.
- 설문 문항/척도 버튼: 기존 `.progress-track`, `.likert-row` 클래스 재사용(선택된
  버튼 강조 스타일만 추가).
- 결과 요약 카드: 카테고리 점수 박스 3개 가로 배치(`.summary-box` 신규).

## 제외 범위

- 실제 이미지 업로드/저장 기능 없음 — 사진 턴은 항상 동일한 중립 썸네일만 표시.
- 설문 응답은 학생이 실제로 입력하지 않음 — 전부 사전에 정해진 스크립트 재생.
- 설문 결과가 교사 화면(`js/screens/teacher.js`)의 실제 데이터와 연동되지는 않음
  (이번 범위는 학생 화면의 데모 애니메이션에 한정).
- 시나리오 재생 중 일시정지 상태에서의 되감기(특정 턴으로 이동) 등 세부 재생 컨트롤은
  포함하지 않음 — 일시정지/재생/처음부터 다시만 지원.
